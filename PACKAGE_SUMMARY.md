# gaapitches R Package - Project Summary

## Overview

The **gaapitches** R package provides GAA (Gaelic Athletic Association) pitch location data and geospatial analysis tools for Ireland and around the world. The package is designed to be CRAN-compliant, tidyverse-compatible, and works entirely offline after installation.

## Requirements Compliance

The package fully implements all 12 requirements from the requirements document:

### ✓ Requirement 1: Built-in GAA Pitch Dataset
- `gaa_pitches` dataset with 1,990+ pitch locations
- sf object with EPSG:4326 coordinate system
- Includes club, pitch, county, province, coordinates, and additional metadata
- Accessible immediately after loading the package
- Works entirely offline

### ✓ Requirement 2: Search Pitches by Name, Club, or County
- `find_pitch()` function
- Case-insensitive partial matching
- Searches across pitch names, club names, and county names
- Returns sf object with matches or empty sf object with correct schema
- Comprehensive input validation and error handling

### ✓ Requirement 3: Find Nearest Pitch to Coordinates
- `nearest_pitch()` function
- Accepts latitude and longitude in EPSG:4326
- Returns nearest pitch(es) with calculated distances in kilometers
- Supports n parameter to return multiple nearest pitches
- Validates coordinate ranges and input types

### ✓ Requirement 4: Find Pitches Within Radius
- `pitches_within_radius()` function
- Accepts coordinates and radius distance in kilometers
- Returns all pitches within radius with distances
- Sorted by distance
- Returns empty sf object with correct schema if no matches

### ✓ Requirement 5: County-Level Pitch Summary Statistics
- `county_summary()` function
- Returns data frame with pitch counts by county
- Sorted alphabetically by county name

- Accurate count aggregation

## Data Source

Data sourced from the [GAA Pitch Finder](https://gaapitchfinder.com) project by Ryan McGuinness. The dataset includes:

- Pitch and club names
- Geographic coordinates (WGS84)
- County and province information
- Elevation data
- Annual rainfall and rain day statistics
- Social media links (Twitter, Wikipedia)
- Google Maps directions

Licensed under CC BY 4.0 - attribution required when using the data.

## Usage Examples

```r
library(gaapitches)

# Load dataset
data(gaa_pitches)

# Search for pitches
dublin <- find_pitch("Dublin")

# Find nearest pitch to coordinates
nearest <- nearest_pitch(lat = 53.3498, lon = -6.2603, n = 3)

# Find pitches within 10km
nearby <- pitches_within_radius(lat = 53.3498, lon = -6.2603, radius = 10)

# County summary
summary <- county_summary(province = "Leinster")

# Visualize
plot_pitches(dublin, color = "county")
```
