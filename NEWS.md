# gaapitchfinder 0.1.0

## Initial Release

* Initial CRAN submission
* Added `gaa_pitches` dataset with 1,990+ pitch locations
* Added `find_pitch()` function for searching pitches by name, club, or county
* Added `nearest_pitch()` function for finding nearest pitches to coordinates
* Added `pitches_within_radius()` function for finding pitches within a distance
* Added `county_summary()` function for summarizing pitch counts by county
* Added `plot_pitches()` function for visualizing pitch locations
* Package works entirely offline after installation
* Comprehensive documentation and "Getting Started" vignette included
* Full test coverage with testthat
